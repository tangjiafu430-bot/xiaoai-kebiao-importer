小爱课表导入器

教务系统课表 → 小爱课表 App（纯网页版）

使用步骤

  1. 校园网内打开教务系统，安装并运行 油猴提取脚本，复制课表 JSON
  2. 在小爱 App 课表页面抓取 Debug 信息（含 appId / serviceToken / deviceId）
  3. 在下方表单填入凭据 + 粘贴 JSON，点击导入
如何获取小爱凭据？（点击展开）

小爱 App 的课表 H5 页面 URL 里会带 ?appId=xxx&serviceToken=xxx&deviceId=xxx，复制这三个值即可。也可在小米浏览器开发者工具里抓包获取。
