小爱课表导入器

教务系统课表 → 小爱课表 App（纯网页版，永久在线）

使用步骤

  1. 在校园网内打开教务系统课表页，点书签栏的「📚 提取课表」按钮（书签见下方第 1 步）
  2. 回到本页，点「↩ 已提取？粘贴 JSON」会自动从剪贴板读入；若没自动，手动 Ctrl+V 粘贴
  3. 粘贴小爱 App 的 Debug JSON（凭据自动识别）→ 点导入
如何获取小爱凭据？（点击展开）

小爱 App 的课表 H5 页面 URL 里会带 ?appId=xxx&serviceToken=xxx&deviceId=xxx。也可在小爱 App 课表页面长按或菜单里找「Debug 信息 / 调试 JSON」，复制整段粘到下方第 3 步的框里，自动识别。
