📘 怎么用？
  1. 点「📚 复制提取书签」→ 浏览器会复制一段 javascript: 开头的链接
  2. 把这条链接拖到浏览器书签栏（或右键书签 → 添加网页 → 粘贴到网址栏）
  3. 打开教务系统（上面任一链接）→ 登录 → 进入「学期理论课表」或个人中心课表
  4. 点书签栏里的「提取课表」→ 自动复制课表 JSON 到剪贴板，并在页面右下角显示提示
  5. 回本页下方「3 · 粘贴课程 JSON」一栏 → 课表 JSON 会自动填入（已开剪贴板自动识别）

替代方案：直接用油猴插件，在脚本管理里新建脚本粘贴内容即可（点上面「📋 复制油猴脚本内容」→ 在油猴编辑器里粘贴保存）。

2 · 选择目标课表

课程将写入选中的课表；也可以新建一个（例如「2026 春」），导入后再去小爱 App 里切换。

3 · 粘贴课程 JSON

标准格式：[{"name":"高等数学","teacher":"张三","position":"A101","day":1,"sections":"1,2","weeks":"1-16周(单)"}] —— 字段名宽松兼容（courseName/老师/教室/星期 都认），周次支持 1-16周(单)、1至16 等写法。

课表设置（节数 / 时间表）

来自教务系统的课表设置，导入时一并同步到小爱（合并到现有 setting，不清空背景等）。节数和时间可手动修改。

4 · 管理课表

查看当前课表已有课程、单条删除、全部清空，或导出为标准 JSON 备份/迁移。

接口协议逆向自「小爱课程导入」APK · 数据只经过你的电脑和小爱服务器
